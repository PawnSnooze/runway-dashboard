# Runway dashboard — hosten op Vercel

Dit mapje bevat je dashboard als een echte, hostbare website
(`index.html`). Zelfde route als bij de backend.

## Stap 1 — Nieuwe GitHub-repository
1. Ga naar github.com → **New repository**
2. Naam: `runway-dashboard`
3. Geen README/gitignore/license aanvinken
4. **Create repository**

## Stap 2 — Bestand uploaden
1. Klik op **"uploading an existing file"**
2. Sleep `index.html` erin
3. **Commit changes**

## Stap 3 — Importeren in Vercel
1. Ga naar vercel.com → **Add New** → **Project**
2. Kies **Import** naast `runway-dashboard`
3. Geen environment variables nodig deze keer — dit bestand haalt
   alleen data op bij je al werkende backend
4. **Deploy**

## Stap 4 — Klaar
Je krijgt een eigen link zoals `runway-dashboard-nu.vercel.app`.
Die kun je bookmarken op je telefoon — werkt gewoon in elke browser,
geen preview-beperkingen meer.
